# Age Checker

A simple and interactive web application that checks a user's age and displays their age category.

This project was built to practise JavaScript conditional statements, input validation, DOM manipulation, and CSS class management.

## Features

- Enter your age and click **Check Age**.
- Display the appropriate age category:
  - **Child:** 1–12 years old
  - **Teenager:** 13–17 years old
  - **Adult:** 18 years and older
- Validate user input:
  - Prevent empty submissions.
  - Reject ages below 1.
  - Reject decimal numbers.
- Display helpful error messages.
- Change the result box colour based on the age category.
- Reset the previous result when the input changes.
- Responsive design with a purple colour theme.

## Technologies Used

- **HTML5** — Page structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Application logic and user interaction

## How to Use

1. Open the application in your browser.
2. Enter your age.
3. Click **Check Age**.
4. View your age category.
5. Change your age to check another result.
